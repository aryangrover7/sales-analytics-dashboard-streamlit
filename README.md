# 📊 Sales Analytics Dashboard

An interactive **Sales Analytics Dashboard** built with **Python, Pandas, and Streamlit** to analyze sales performance through KPIs, filters, and interactive visualizations.

The dashboard uses a demo sales dataset by default and allows users to explore the data through category filters and dynamically calculated metrics.

## 🚀 Live Demo

The application is deployed on two platforms:

* **Render:** https://sales-analytics-dashboard-streamlit-jqbh.onrender.com/
* **Streamlit Community Cloud:** https://sales-analytics-dashboard-data.streamlit.app/

## ✨ Features

* 📈 Overall sales performance
* 💰 Total Sales, Total Units, and Total Products KPIs
* 🔎 Category-based filtering
* 📊 Sales analysis by product
* 📊 Sales analysis by category
* 🏆 Top products by sales and units
* 📋 Interactive sales data table
* ➕ Add new sales records
* 📱 Responsive interface for desktop and mobile
* 🗂️ Demo dataset included for easy exploration

## ⚙️ How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/aryangrover7/sales-analytics-dashboard-streamlit.git
```

### 2. Navigate to the project directory

```bash
cd sales-analytics-dashboard-streamlit
```

### 3. Install the dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit app

```bash
streamlit run app.py
```

The application will open in your browser.

## 📊 Dashboard Overview

### Overall Performance

Displays key business metrics including:

* Total Sales
* Total Units
* Total Products

### Filters

Users can filter the dashboard by product category and view updated metrics and visualizations.

### Sales Visualizations

The dashboard includes visualizations for:

* Sales by Product
* Sales by Category
* Top Products by Sales
* Top Products by Units Sold

### Data Interaction

Users can also add new sales records directly through the sidebar, allowing the dashboard to update dynamically.
